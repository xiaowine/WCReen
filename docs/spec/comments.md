# 注释规范

> 本文件是 [`AGENTS.md`](../../AGENTS.md) 索引下的规范之一。
> 适用于本仓库的一切手写代码与脚本。

---

## 1. 语言与格式

- 注释一律**中文**。
- 格式**跟随各语言既有风格**，不新造约定：

| 语言 | 格式 |
|---|---|
| Kotlin / Java | KDoc `/** ... */` |
| C / C++ | Doxygen `///` 或 `/** ... */` |
| Rust | rustdoc `///`（条目）/ `//!`（模块） |
| Shell / 构建脚本 | `#` |

---

## 2. 必须写文档注释的对象

以下对象**全部**必须有文档注释：

- 类 / 接口 / 对象 / 枚举，**及其成员**；
- 函数 / 方法；
- 结构体（struct）/ 联合体 / 类（C/C++），**及其成员**；
- 顶层常量与全局变量；
- 关键字段。

### 2.1 写什么

| 对象 | 必须说明 |
|---|---|
| 类 / 结构体 | 职责 + 为什么需要它 + 与其他模块的关系或约束 |
| 函数 / 方法 | 作用 + 参数 + 返回值与抛出的异常（有则写）+ 副作用与前置条件（非显然时） |
| 结构体成员 / 字段 | 语义 + **单位**（ms / µs / px / 字节序 …）+ 离散取值的含义（取值有限时列全） |
| 常量 | 值的来源或依据（协议规定 / 实测 / 系统限制） |

### 2.2 示例（Kotlin）

```kotlin
/**
 * 虚拟屏的 flag 组合与位解码。
 *
 * 独立可信屏依赖 [TRUSTED]（1 shl 10），该位只有系统或 shell 能设置，
 * 普通 App 设置会被 DisplayManagerService 拒绝（见 agent/module.md §3 不变量 1 / 2）。
 */
object DisplayFlags {

    /** 可信屏：解除「只有 allowEmbedded 的 Activity 才能启动」的限制。 */
    const val TRUSTED: Int = 1 shl 10

    /**
     * 按名字取 [DisplayInfo] 的字段。
     *
     * @param name 字段名，跨版本可能变化
     * @return 字段值；字段不存在时返回 null（不抛异常）
     */
    fun field(info: DisplayInfo, name: String): Any?
}
```

## 3. 函数体内部注释

- 按**复杂度**决定，**不强制逐行注释**。
- **必须**解释「为什么」：
  - 非显然的约束与顺序依赖；
  - 魔数的来源（实测数据 / 系统常量 / 协议规定）；
  - 平台坑与绕过手段（以及绕过的原因）。
- **不要**解释显而易见的「是什么」，不要写复读机式注释。
- 禁止用注释屏蔽死代码 —— 不需要的代码直接删。

### 3.1 好 / 坏对照

```kotlin
// ❌ 复读代码，零信息量
// 把 encoder 设为 null
encoder = null

// ✅ 解释为什么，以及不这么做会怎样
// 必须先拆虚拟屏再拆编码器：反过来的话，编码器的输入 Surface 会在虚拟屏
// 仍在渲染时失效，表现为后续帧直接丢失。
virtualDisplay.release()
encoder.release()
```

---

## 4. 同步要求

- 注释必须与代码**同步**：改行为就改注释。
- 失效注释按**删除**处理，不留「已废弃 / 暂时保留 / 曾经……」的僵尸说明。
- 禁止保留已注释掉的旧实现；需要旧版本时用 git 历史，不留在源码里。
